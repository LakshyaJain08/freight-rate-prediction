# Freight Rate Prediction ML Model Report

## 1. Key Findings from Exploring the Data
- **Temporal Nature:** The training data spans from January to October 2025, and the task requires predicting for November and December. This clearly indicates a time-series forecasting component where market conditions change over time.
- **Categorical Complexity:** Variables like `pickup` and `delivery` are high-cardinality categorical features (64 unique values each). Similarly, `equipment` type plays a significant role in determining rates.
- **Missing Information in December Inputs:** The target input for the December predictions (`december-chart-inputs.csv`) only contains 7 core columns. It lacks `market_index` and `quote_signal`, meaning these either needed to be omitted, or more practically, imputed/defaulted when making the final December predictions if they were used during training.
- **Price Distribution:** The `posted_rate` ranges significantly, suggesting tree-based algorithms or models robust to outliers would perform well.

## 2. Data Quality Issues and How They Were Addressed
- **Missing Values:** The `weight`, `market_index`, and `quote_signal` columns had missing values.
  - **Resolution:** I addressed this by using median imputation derived from the training set. A simple median imputation avoids data leakage and provides a stable, robust filler for the XGBoost model.
- **Inconsistent Columns for December:** The December input data did not have all the columns present in the training set (e.g., `market_index`, `quote_signal`, geo-coordinates).
  - **Resolution:** I artificially added these columns filled with `NaN`s to the December set during the feature engineering phase, and allowed the median imputer to fill them in identically to how it handles missing data in the training set.

## 3. Reasoning Behind the Chosen Model
I chose **XGBoost (Extreme Gradient Boosting)** for the following reasons:
1. **Handling Non-linearities:** Freight rates are highly non-linear with respect to distances, equipment types, and time of year. Tree-based models capture these complex interactions exceptionally well.
2. **Native Categorical Support:** XGBoost has built-in support for categorical variables (`enable_categorical=True`). This avoided the need to vastly expand the feature space with one-hot encoding for the 64 pickup and delivery cities.
3. **Robustness to Missing Data:** While I used a median imputer, XGBoost internally handles missing data effectively.
4. **Performance:** It trains quickly and typically outperforms other standard tabular models like Random Forest or Linear Regression without requiring deep neural networks.

## 4. Training and Validation Approach
- **Validation Split:** To ensure the validation metrics are representative of the real-world prediction task (predicting November/December based on Jan-Oct), I used a **Time-based split**.
  - **Training Set:** January 1, 2025 – September 30, 2025
  - **Validation Set:** October 1, 2025 – October 31, 2025
- **Hyperparameter Tuning:** I set sensible defaults that prevent overfitting: `n_estimators=300`, `learning_rate=0.05`, `max_depth=6`, and slightly constrained tree building (`subsample=0.8`, `colsample_bytree=0.8`).
- **Final Training:** After evaluating the model on the October holdout set and verifying reasonable RMSE/MAE metrics, the model was **retrained on the entire dataset** (Jan to Oct) before making predictions on the final `validation.csv` (Nov) and `december-chart-inputs.csv` (Dec) to leverage all available historical data.

## 5. Explainable AI (XAI) Analysis
To ensure model decisions are transparent and trustworthy for logistics operators, three XAI techniques were implemented:
1. **Global Feature Importance (Gain Metric):** Measures how much each feature contributed to reducing the model's loss across all decision trees.
   - *Key Insight:* Distance, pickup/delivery locations, and equipment type provided the highest overall predictive power.
   - *Artifact:* `output/xai_feature_importance.png`
2. **SHAP Global Directional Summary (Beeswarm Plot):** Uses Shapley values from game theory to show both the magnitude and directional impact of each feature.
   - *Key Insight:* High distance values strongly drive positive SHAP values (increasing freight rate), while Reefer / Flatbed equipment command higher premiums compared to Dry Van.
   - *Artifact:* `output/xai_shap_summary.png`
3. **SHAP Local Explanation (Waterfall Plot):** Breaks down the exact additive contributions for individual freight loads from the expected base rate to the final predicted rate.
   - *Key Insight:* Allows freight brokers to audit exactly why a specific load was quoted at a particular price by decomposing distance, weight, seasonality, and equipment adjustments.
   - *Artifact:* `output/xai_shap_waterfall.png`
